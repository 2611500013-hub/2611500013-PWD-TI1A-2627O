Bukti Belajar P1
Fungsi: dokumentasi capaian pembelajaran P1
1. Konsep Dasar Pemrograman Web
   Pemrograman web dasar adalah proses pembuatan dan pengembangan halaman situs web menggunakan tiga pilar utama yaitu HTML, CSS, dan JavaScript.
2. Arsitektur Klien-Peladen
   Arsitektur klien-peladen (atau client-server) adalah struktur aplikasi terdistribusi yang membagi tugas antara pihak peminta layanan (klien) dan pihak penyedia layanan (peladen).
3. HTTP Request dan Response
   HTTP request dan response adalah siklus komunikasi dasar antara klien (seperti browser atau aplikasi) dan server di internet yang dapat dipelajari lebih lanjut pada penjelasan HTTP, Permintaan & Respons.
4. HTML, CSS, JavaScript, PHP, MySQL
   HTML, CSS, JavaScript, PHP, dan MySQL adalah komponen utama yang saling bekerja sama untuk membangun dan menjalankan sebuah website
5. Hubungan Antarteknologi
   Hubungan antarteknologi adalah keterkaitan, ketergantungan, dan interaksi antara berbagai jenis teknologi yang saling mendukung untuk menciptakan sistem yang lebih canggih, efisien, dan cerdas. Di era modern, tidak ada teknologi yang berdiri sendiri; satu inovasi sering kali menjadi fondasi atau pemicu bagi lahirnya inovasi lainnya.
